# Registro fotográfico

[English](README.md) · [Início](../README.pt-BR.md)

As fotografias originais documentam a montagem e o dispositivo concluído. Envie os 16 arquivos JPEG renomeados localmente diretamente para esta pasta, mantendo seus nomes. Os READMEs e guias de hardware/desenvolvimento referenciam esses caminhos. As imagens aparecerão depois do upload.

| Arquivos | Etapa |
| --- | --- |
| arduino-01.jpeg | Placa e conexão USB inicial |
| arduino-02.jpeg | Teste de disposição dos seis botões |
| arduino-03.jpeg | Três botões e três LEDs |
| arduino-04.jpeg | Primeiras ligações dos LEDs |
| arduino-05.jpeg, arduino-06.jpeg | Primeiro protótipo montado, vários ângulos |
| arduino-07.jpeg a arduino-16.jpeg | Fotografias da sessão final |
| arduino-08.jpeg | Capa escolhida: controlador final de dois LEDs |

O conjunto final também contém uma foto apenas da placa e ângulos repetidos; nem todas retratam o circuito concluído. Fotos anteriores com três LEDs são históricas, não instruções de ligação definitiva.
